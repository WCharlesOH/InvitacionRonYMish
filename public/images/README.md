# Fotos de los novios

Coloca aquí las fotos con **estos nombres exactos**. Mientras no existan, la
página muestra marcadores elegantes (no se rompe nada).

| Archivo                 | Dónde aparece                                   | Sugerencia            |
| ----------------------- | ----------------------------------------------- | --------------------- |
| `novios-hero.jpg`       | Portada (arriba de "¡Nos casamos!"), con "R&M". | Vertical (retrato).   |
| `novios-countdown.jpg`  | Fondo de la Cuenta Regresiva.                   | Horizontal, amplia.   |
| `novios-final.jpg`      | Fondo de la sección final ("¡Te esperamos!").   | Horizontal, amplia.   |
| `novios-1.jpg`          | Galería (debajo de los padrinos) — foto 1.      | Vertical (3:4).       |
| `novios-2.jpg`          | Galería — foto 2.                               | Vertical (3:4).       |
| `novios-3.jpg`          | Galería — foto 3.                               | Vertical (3:4).       |
| `novios-4.jpg`          | Galería — foto 4.                               | Vertical (3:4).       |

**Notas**

- Formatos: `.jpg` o `.png`. Optimiza el peso (< 500 KB c/u idealmente).
- Los fondos (`countdown` / `final`) llevan una capa oscura encima para que
  el texto se lea; elige fotos donde eso quede bien.
- Para cambiar los nombres o rutas, edita `photos` en
  `src/data/eventData.json`.
